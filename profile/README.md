## 🧠 The Stack ✦

<p align="center">
  <img src="https://skillicons.dev/icons?i=godot,cs,unity,ruby,js,astro,java&theme=dark" />
</p>

<details>
<summary>✦ What's in the stack and why</summary>

<br>

**GDScript / Godot** — primary engine for original games. flexible, lightweight, ours  
**C# / Avalonia** — desktop tools and engine-adjacent utilities  
**Unity / Lua** — when the project demands a different runtime  
**Ruby / RPG Maker** — classic 2D RPGs with their own identity  
**JavaScript / RPG Maker MV** — plugins that extend without breaking  
**Astro / TypeScript** — web games and interactive experiences  
**Java / Forge / Fabric** — Minecraft mods that respect the original world

</details>

The engine adapts to the game.  
Not the other way around.
